# Project Context: safeAI

## Philosophical & Ethical Operating Context
At the start of every session, read and apply the operating context in `catholicism/BELIEF.md` from the `jb-colletta/belief` repository (specifically attending to human dignity, subsidiarity, solidarity, and *Babel or Jerusalem* when evaluating AI tools).

## Project Mission & Guardrails
- **Goal:** Build open-source software that any non-profit organization can use to assess gaps in safe AI use and take actionable steps to close those gaps.
- **Core Framework:** Anchor assessments and remediation workflows around the **seven levels of "Is it safe?"** defined in this repository's source files.
- **Strict Naming Rule:** Keep all code, schemas, documentation, UI labels, and sample data completely generic for any non-profit organization or software vendor. **Never reference MinistryPlatform, Realm, or any specific vendor product**—even if they appear in early reference notes.
